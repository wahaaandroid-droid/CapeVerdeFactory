# カーボベルデ工場パワハラおじさん

ブラウザで動く 2D ドット絵の「工場自動化 × タワーディフェンス × ローグライク」MVPです。

## 遊び方

- クリック/タップ: 選択中の施設をグリッドに設置
- R: 施設やコンベアの向きを回転
- 右クリック: 建設キャンセル
- 1から5: 建設メニューのショートカット

採掘機で資源を掘り、コンベアで弾薬工場へ運び、弾薬をタレットへ供給して海から来るドローンを防衛します。
10ウェーブ生存するとクリアです。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`dist` が生成されるので、そのまま Vercel の静的ホスティングとして公開できます。

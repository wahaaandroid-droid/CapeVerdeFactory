# カーボベルデ工場パワハラおじさん

ブラウザで動く 2D ドット絵の「工場自動化 × タワーディフェンス × ローグライク」MVPです。

## 遊び方

- クリック/タップ: 選択中の施設をグリッドに設置
- 準備完了ボタン: 戦闘フェーズを開始
- R: 設置予定の向きを回転
- Q / 向き変更モード: 既存施設をクリックして向きを変更
- マウスホイール: マップをズーム
- 右クリックドラッグ / Space + ドラッグ: マップを移動
- WASD / 矢印キー: マップを移動
- O: 戦闘中に建材を消費して過負荷を発動
- 1から4: 建設メニューのショートカット

採掘機で鉄を掘り、コンベアで弾薬工場へ物理的に運び、弾薬工場に格納された鉄から弾薬を作ります。
弾薬もコンベアでタレットへ運び、タレット自身に弾薬がストックされている時だけ攻撃します。
準備フェーズと戦闘フェーズを繰り返して、海から来るドローンを防衛します。
準備中は次ウェーブの敵構成と侵攻レーンを確認できます。
ウェーブ後の「工場長命令」では、搬送複製、通常弾の範囲化、帯電防壁、残業指令強化など、ランごとの工場方針が変わるアップグレードを選びます。
10ウェーブ生存するとクリアです。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

`dist` が生成されるので、そのまま Vercel の静的ホスティングとして公開できます。
